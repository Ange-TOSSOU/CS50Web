# CS50 Web

CS50 Web is an introduction into the design and implementation of web apps with Python, JavaScript ans SQL using frameworks like Django, React, and Bootstrap. It's a course delivered by the Harvard University which covered the topics below :

- HTML, CSS
- Git
- Python
- Django
- SQL, Models, and Migrations
- JavaScript
- User Interfaces
- Testing, CI/CD
- Scalability and Security

Find more about this course on their [OpenCourseWare][cs50web_material].

The course contains a bunch of problem sets. Some of them can be really challenging.
I created this repository to save all my solutions for those problems. Feel free to try its out, compare its to yours and give me your feedback if needed.
